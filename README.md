# 🎬 Cinemate - Movie Recommendation Website

## 📌 About the Project
Cinemate is a movie recommendation website designed
to help users discover movies based on their interests.

## 🎯 Objectives
- Recommend movies to users.
- Provide an easy-to-use interface.
- Help users discover interesting movies.

## ✨ Features
- Movie recommendations
- Simple user interface
- Easy navigation
- Movie details

## 🛠️ Technologies Used
- Python
- Tkinter

## 🚀 How to Run
1. Download or clone this repository.
2. Install Python.
3. Run the following command:

python main.py

Student Mini Project
